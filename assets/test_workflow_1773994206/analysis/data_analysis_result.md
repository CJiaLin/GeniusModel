## 4. 建模建议（针对RMSE优化）

### 4.1 算法选择建议

| 算法类型 | 推荐模型 | 适用理由 |
|----------|----------|----------|
| **树集成** | XGBoost / LightGBM / CatBoost | 处理混合类型数据、自动处理缺失值、捕捉非线性关系 |
| **线性模型** | Ridge / Lasso / ElasticNet | 作为基准模型，解释性强 |
| **集成方法** | Stacking / Voting | 组合多个模型降低RMSE |

### 4.2 数据预处理策略

1. **缺失值处理**（数据清洗重点）：
   - **类别型"NA"**: 转换为"None"或"Missing"类别（如PoolQC: "No Pool"）
   - **数值型**: 中位数填充或使用模型预测（如LotFrontage）
   - **高缺失率特征(>80%)**: 考虑删除或创建二元指示特征（是否有该设施）

2. **特征编码**：
   - 低基数分类变量（<10类别）: One-Hot编码
   - 高基数分类变量（如Neighborhood）: 目标均值编码或CatBoost原生处理
   - 序数变量（如OverallQual）: 可保留数值或序数编码

3. **目标变量变换**：
   - **建议对SalePrice进行对数变换**: `log(SalePrice)`
   - 原因：房价通常右偏，对数变换可使分布更接近正态，降低RMSE对大误差的敏感性
   - 注意：最终预测需进行指数变换还原

4. **异常值处理**：
   - 检查`GrLivArea`与`SalePrice`的散点图，移除明显异常点
   - 检查极端大的`LotArea`值

### 4.3 RMSE优化技巧

| 技巧 | 说明 | 预期收益 |
|------|------|----------|
| **对数变换目标** | 减少大值区域误差权重 | 显著提升RMSE |
| **交叉验证策略** | 5-10折分层K折 | 稳定评估泛化能力 |
| **超参数调优** | GridSearch / Optuna | 找到最优模型配置 |
| **特征选择** | 基于重要性过滤 | 减少噪声，防止过拟合 |

## 5. 下一步建议：数据清洗 ➡️

### 🎯 强烈推荐立即进行数据清洗

根据当前分析结果，**数据清洗是下一步的关键工作**。当前数据集存在严重的缺失值问题，直接建模将导致：

- ❌ 模型无法处理大量缺失值（非树模型）
- ❌ 错误解释"NA"的含义（NA≠缺失，往往代表"无"）
- ❌ 高缺失率特征引入噪声

### 建议的数据清洗步骤

```
步骤1: 处理高缺失率特征（>80%）
   ├─ 删除：PoolQC, MiscFeature（或保留为二元特征"HasPool"）
   ├─ 填充：Alley→"NoAlley", Fence→"NoFence"

步骤2: 处理中等缺失率特征（20%-60%）
   ├─ MasVnrType: 填充为"None" + MasVnrArea填充0
   └─ FireplaceQu: 填充为"NoFireplace"

步骤3: 处理Garage相关特征
   ├─ 统一处理81个缺失样本
   ├─ GarageType→"NoGarage", GarageFinish→"NoGarage"
   └─ GarageYrBlt: 填充0或YearBuilt

步骤4: 处理LotFrontage
   └─ 按Neighborhood分组使用中位数填充

步骤5: 异常值检测
   └─ 检查并处理GrLivArea vs SalePrice的极端异常点
```
