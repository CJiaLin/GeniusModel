$$SalePrice_{log} = \log(SalePrice)$$

预期效果：
- 偏度从 1.88 → 接近0
- 使模型更关注相对误差（百分比误差），更符合房价预测的业务逻辑
- 降低异常值影响，提升RMSE评估指标表现
