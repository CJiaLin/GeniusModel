## 4. 建模建议

### 4.1 问题类型识别
- **任务类型**：回归问题（预测连续值目标）
- **数据特性**：表格数据，混合数值与分类特征
- **样本量**：1,460条（属于小样本，需注意过拟合）

### 4.2 特征工程建议

| 步骤 | 建议操作 |
|:---|:---|
| **缺失值处理** | PoolQC等4个极高缺失特征 → 删除或编码为"None"<br>Garage相关特征 → 缺失表示"无车库"，创建指示变量<br>LotFrontage → 按Neighborhood分组中位数填充 |
| **编码策略** | 低基数分类特征 → One-Hot Encoding<br>有序分类特征（如OverallQual） → 标签编码保持顺序<br>高基数特征（如Neighborhood） → Target Encoding |
| **特征构建** | 创建HouseAge = CurrentYear - YearBuilt<br>创建IsNew = YearBuilt == YearRemodAdd<br>创建TotalSF = 各面积特征求和 |
| **特征缩放** | 树模型：无需缩放<br>线性模型/神经网络：StandardScaler或RobustScaler |

### 4.3 模型选择建议

| 优先级 | 模型 | 理由 |
|:---|:---|:---|
| 1 | **XGBoost/LightGBM** | 处理缺失值能力强，对异构特征友好 |
| 2 | **Random Forest** | 稳健基线，不易过拟合 |
| 3 | **Ridge/Lasso** | 验证线性关系，特征选择 |
| 4 | **Stacking Ensemble** | 结合多种模型提升性能 |
