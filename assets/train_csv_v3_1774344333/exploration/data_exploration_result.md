## 6. 特征工程建议

### 6.1 目标变量变换

```python

# 理由：偏度0.81的右偏分布，对数变换可改善正态性
```

### 6.2 处理多重共线性

| 问题特征对 | 建议工程方案 | 新特征示例 |
|------------|--------------|------------|
| GarageCars + GarageArea | 保留面积，创建车位效率特征 | `GarageEfficiency = GarageArea / (GarageCars + 1)` |
| TotalBsmtSF + 1stFlrSF | 创建地下室占比特征 | `BsmtRatio = TotalBsmtSF / (1stFlrSF + 1)` |
| GrLivArea + TotRmsAbvGrd | 创建平均房间面积特征 | `AvgRoomSize = GrLivArea / (TotRmsAbvGrd + 1)` |
| YearBuilt + GarageYrBlt | 创建车库与房屋建造时间差 | `GarageAgeDiff = GarageYrBlt - YearBuilt` |
