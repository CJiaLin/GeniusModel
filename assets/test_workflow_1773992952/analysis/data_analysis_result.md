## 4. 建模建议 🎯

### 4.1 针对房价预测任务的策略

| 建议类别 | 具体策略 |
|----------|----------|
| **目标变换** | 对 SalePrice 进行 `np.log1p` 变换，降低异常值影响，提升RMSE表现 |
| **特征工程** | 创建总面积特征（GrLivArea + TotalBsmtSF）、房龄特征、翻新标志等 |
| **缺失值处理** | 结构性缺失填充"None"，真实缺失用中位数/众数或模型预测填充 |
| **编码方式** | 有序分类特征用Label Encoding，名义特征用One-Hot或Target Encoding |
| **异常值处理** | 检查并处理面积异常大但价格低的样本（可能为异常值） |

### 4.2 推荐模型路径

```
原始数据
   ↓
数据清洗（处理缺失值、异常值）
   ↓
特征工程（创建衍生特征、编码）
   ↓
模型选择（建议尝试：XGBoost / LightGBM / 集成模型）
   ↓
交叉验证（K-Fold，注意目标变换后的逆变换）
   ↓
生成预测（对预测结果进行指数还原）
```

### 4.3 RMSE优化要点

1. **大误差惩罚**: RMSE对大误差敏感，需特别关注高价位房屋的预测准确性
2. **目标变换技巧**: 在log空间优化，回到原始空间计算RMSE
3. **交叉验证策略**: 使用K-Fold确保模型泛化能力
