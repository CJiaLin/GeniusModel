## 🎯 4. 建模建议（针对RMSE优化）

### 4.1 数据预处理策略

| 步骤 | 具体操作 | 原因 |
|------|----------|------|
| **缺失值处理** | 分类特征填"None"，数值特征分组填充 | 保留"无设施"信息 |
| **对数变换** | `log1p(SalePrice)` | 处理右偏分布，降低RMSE |
| **异常值处理** | 删除或截断极端值（>3σ或IQR方法） | 提高模型鲁棒性 |
| **特征编码** | One-Hot / Label Encoding / Target Encoding | 处理分类变量 |
| **特征缩放** | StandardScaler / RobustScaler | 对梯度下降类模型必要 |

### 4.2 推荐模型（按RMSE性能排序）

| 优先级 | 模型 | 优势 | 注意事项 |
|--------|------|------|----------|
| 1 | **XGBoost / LightGBM** | 处理缺失值能力强，对异常值鲁棒 | 需调参防止过拟合 |
| 2 | **Random Forest** | 稳定性好，特征重要性可解释 | 对高基数类别处理一般 |
| 3 | **Ridge / Lasso Regression** | 快速基线，可解释性强 | 需充分特征工程 |
| 4 | **Stacking Ensemble** | 组合多个模型，提升精度 | 复杂度较高 |

### 4.3 特征工程方向

1. **面积聚合特征**：
   - 总面积 = GrLivArea + TotalBsmtSF + GarageArea
   - 每平米价格 = SalePrice / 总面积

2. **时间特征**：
   - 房龄 = 当前年份 - YearBuilt
   - 翻新后年数 = 当前年份 - YearRemodAdd
   - 是否为新房 = (YearBuilt == 销售年份)

3. **质量组合**：
   - QualityScore = OverallQual × OverallCond
   - 高质高价交互项

4. **类别特征降维**：
   - Neighborhood 价格分组（高/中/低价位区）
