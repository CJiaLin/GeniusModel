#### 6.1.3 时间特征工程
```python
# 房龄和翻新信息
df['HouseAge'] = df['YrSold'] - df['YearBuilt']

df['SinceRemod'] = df['YrSold'] - df['YearRemodAdd']
```

#### 6.1.4 质量-面积交互项

### 6.2 分类变量编码策略

**高基数分类变量**（如Neighborhood, MSSubClass）：
- 建议：目标编码（Target Encoding）或有序编码

**有序分类变量**（如OverallQual, ExterQual）：
- 建议：标签编码（Label Encoding）映射为数值

**二元分类变量**：
- 建议：One-Hot或简单0/1映射

## 7. 建模准备建议

### 7.1 数据划分策略
- 建议采用**K折交叉验证**（K=5或10）
- 考虑到房价分布的右偏性，建议使用**分层抽样**确保每折中价格分布一致

### 7.2 模型选择建议
基于数据特征：
- **基础模型**：Ridge/Lasso（处理多重共线性，自动特征选择）
- **树模型**：XGBoost/LightGBM（自动处理非线性关系，对异常值鲁棒）
- **集成策略**：Stacking（结合线性模型和树模型优势）

### 7.3 评估指标注意事项
- **RMSE**：对高房价的预测误差惩罚更重
- 建议同时监控**MAE**和**R²**，全面评估模型性能
- 考虑在log尺度上计算RMSE（等价于RMSLE），降低右偏影响
