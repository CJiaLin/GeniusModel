## 4. 建模建议 🎯

### 4.1 针对房价预测任务的策略

基于**RMSE评估指标**和**房价预测**特点，建议如下：

#### A. 目标变量处理
- **检查 `SalePrice` 分布**: 房价通常右偏，建议进行**对数变换**（`log(SalePrice)`）以满足线性模型假设
- **验证RMSE计算**: 若在log空间预测，注意转换回原始空间时的偏差校正

#### B. 特征工程建议
| 策略 | 具体措施 |
|:---|:---|
| 高缺失特征处理 | `PoolQC`, `MiscFeature`, `Alley`, `Fence`等缺失率>80%的特征，建议填充为"None"而非删除 |
| 地理特征填补 | `LotFrontage`可基于`Neighborhood`分组中位数填充 |
| 时间特征构造 | 构造`HouseAge` = 当前年份 - `YearBuilt`，`RemodAge`等 |
| 面积特征组合 | 创建`TotalSF` = `GrLivArea` + `TotalBsmtSF`等总面积指标 |
| 质量评分聚合 | 组合多个Quality相关特征创建综合质量评分 |

#### C. 模型选择建议
- **基线模型**: 线性回归、Ridge/Lasso（适合处理多重共线性）
- **集成模型**: Random Forest、XGBoost、LightGBM（处理非线性关系）
- **验证策略**: 5折交叉验证，注意分层抽样保持`SalePrice`分布一致性

#### D. 潜在风险点
- ⚠️ **多重共线性**: 面积类特征高度相关（`GarageCars` vs `GarageArea`）
- ⚠️ **异常值敏感**: RMSE对大误差惩罚重，需识别和处理极端房价
- ⚠️ **时间因素**: 若训练/测试数据时间分布不同，需考虑市场趋势
