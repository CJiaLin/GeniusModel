## 5. 特征工程建议

### 5.1 必须执行的特征工程

#### ✅ 建议 1: 目标变量对数变换
```python
# 消除右偏，使分布更接近正态
df['SalePrice_Log'] = np.log1p(df['SalePrice'])
```
**理由**: 偏度1.27，对数变换可降低偏度，提升线性模型性能。

#### ✅ 建议 2: 处理高相关特征（多重共线性）
```python
# 方案A: 删除冗余特征
# GarageArea与GarageCars高度相关(r=0.891)，保留GarageCars（更直观）
# GarageYrBlt与YearBuilt高度相关(r=0.845)，删除GarageYrBlt
# TotRmsAbvGrd与GrLivArea高度相关(r=0.836)，删除TotRmsAbvGrd

cols_to_drop = ['GarageArea', 'GarageYrBlt', 'TotRmsAbvGrd']
```

#### ✅ 建议 3: 创建面积聚合特征
```python
# 总居住面积 = 地上面积 + 地下室面积
df['TotalSF'] = df['GrLivArea'] + df['TotalBsmtSF']

# 总面积 = 所有楼层面积之和
df['AllSF'] = df['1stFlrSF'] + df['2ndFlrSF'] + df['TotalBsmtSF']
```

#### ✅ 建议 4: 房龄相关特征
```python
# 房屋年龄（建造至今）
df['HouseAge'] = df['YrSold'] - df['YearBuilt']

# 翻新后年龄
df['RemodAge'] = df['YrSold'] - df['YearRemodAdd']

# 是否为翻新房屋
df['IsRemodeled'] = (df['YearRemodAdd'] != df['YearBuilt']).astype(int)
```

### 5.2 推荐执行的特征工程

#### ⭐ 建议 5: 对数变换偏度高的数值特征
```python
# 对偏度 > 1 的特征进行对数变换
skewed_cols = ['LotArea', 'MasVnrArea', 'BsmtFinSF1']
for col in skewed_cols:
    df[f'{col}_Log'] = np.log1p(df[col])
```

#### ⭐ 建议 6: 质量等级编码
```python
# 将分类质量等级转换为数值
quality_map = {'NoBasement': 0, 'Po': 1, 'Fa': 2, 'TA': 3, 'Gd': 4, 'Ex': 5}
df['BsmtQual_Encoded'] = df['BsmtQual'].map(quality_map)
```

#### ⭐ 建议 7: 布尔特征创建
```python
# 是否有地下室
df['HasBasement'] = (df['TotalBsmtSF'] > 0).astype(int)

# 是否有车库
df['HasGarage'] = (df['GarageCars'] > 0).astype(int)

# 是否有壁炉
df['HasFireplace'] = (df['Fireplaces'] > 0).astype(int)

# 是否有泳池
df['HasPool'] = (df['PoolArea'] > 0).astype(int)
```

### 5.3 可选高级特征工程

#### 🔧 建议 8: 交互特征
```python
# 质量与面积的交互
df['Qual_x_Area'] = df['OverallQual'] * df['GrLivArea']

# 房龄与质量的交互
```

#### 🔧 建议 9: 分类特征聚合
```python
# 按Neighborhood聚合房价统计特征
neigh_stats = df.groupby('Neighborhood')['SalePrice'].agg(['mean', 'median'])
```
