### 5.3 业务结论

房价预测的核心逻辑公式：
```
房价 = 基准地价(Neighborhood) × 面积系数(SF) × 质量溢价(Qual)
       + 车库附加值(Garage) - 房龄折旧(Age) + 装修溢价(Remod)
```
关键洞察：
- 质量与面积的**交互效应**强于单独效应（`Qual_TotalSF` IV最高）
- 地段(Neighborhood)是**乘数因子**而非加数，好地段放大所有其他价值
- 房龄带来非线性折旧，新房溢价显著(`IsNewHouse` IV=0.46)
- 卧室/浴室比例反映户型合理性，过高或过低都影响单价
