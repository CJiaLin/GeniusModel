## 7. 建模策略建议

### 7.1 针对RMSE评估的优化
- **对数变换目标变量**：使RMSE在原始尺度上近似于百分比误差
- **交叉验证策略**：K-Fold (K=5或10)，确保各折价格分布一致
- **特征缩放**：对正则化模型（Ridge/Lasso/ElasticNet）必需

### 7.2 推荐模型尝试顺序
1. **Baseline**: 线性回归（验证特征工程效果）
2. **正则化线性**: Ridge/Lasso（处理共线性）
3. **树模型**: Random Forest, Gradient Boosting（XGBoost/LightGBM）
4. **融合策略**: Stacking（线性+树模型）
