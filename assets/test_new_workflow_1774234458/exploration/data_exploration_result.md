## 三、目标变量分析（SalePrice）

### 3.1 基本统计量

| 指标 | 数值 | 解读 |
|------|------|------|
| **均值** | $180,921 | 平均房价 |

| **最大值** | $755,000 | 高端房价 |
| **极差** | $720,100 | 价格跨度大 |
| **偏度** | **1.88** | ⚠️ 显著右偏 |
| **峰度** | **6.54** | ⚠️ 尖峰厚尾特征 |

### 3.2 目标变量分布特征

```
价格分布形态: 右偏分布（正偏态）
               ▲
    频数       │    ╱╲
               │   ╱  ╲
               │  ╱    ╲___
               │ ╱          ╲____
               │╱                  ╲________
               └────────────────────────────► 价格
               低价位        中价位        高价位（长尾）
```

**关键洞察：**
1. **右偏分布**：大多数房屋集中在低-中价位区间，高端房屋形成长尾
2. **对数变换建议**：偏度1.88 > 1，建议进行 `log(SalePrice)` 变换以满足线性模型假设
3. **RMSE考量**：由于评估指标是RMSE，大误差会被放大，需特别关注高价位房屋的预测精度

## 六、特征工程建议

### 6.1 数据变换类

| 优先级 | 变换类型 | 目标特征 | 具体方法 | 预期收益 |
|--------|----------|----------|----------|----------|
| P0 | **对数变换** | SalePrice | `log1p(SalePrice)` | 消除右偏，满足正态假设，降低RMSE对大误差的敏感 |
| P0 | **对数变换** | LotArea, LotFrontage | `log1p(x)` | 处理极端偏态，减少异常值影响 |
| P1 | **标准化** | 所有连续数值特征 | StandardScaler | 使不同尺度特征可比，提升线性模型表现 |

### 6.2 特征创建类

| 新特征名 | 构造方法 | 业务含义 | 预期价值 |
|----------|----------|----------|----------|
| **TotalSF** | `GrLivArea + TotalBsmtSF` | 房屋总使用面积 | 综合空间指标 |
| **TotalBathrooms** | `FullBath + 0.5*HalfBath + BsmtFullBath + 0.5*BsmtHalfBath` | 总浴室当量 | 统一 bathrooms 度量 |
| **HouseAge** | `YrSold - YearBuilt` | 房龄 | 比年份更直观 |
| **RemodAge** | `YrSold - YearRemodAdd` | 翻新后年限 | 反映房屋新旧程度 |
| **IsNewHouse** | `1 if YearBuilt == YrSold else 0` | 是否新房 | 捕捉新房溢价 |
| **Has2ndFloor** | `1 if 2ndFlrSF > 0 else 0` | 是否有二层 | 房屋结构特征 |
| **HasBasement** | `1 if TotalBsmtSF > 0 else 0` | 是否有地下室 | 地下室存在性 |
| **HasGarage** | `1 if GarageArea > 0 else 0` | 是否有车库 | 车库存在性 |
| **HasPool** | `1 if PoolArea > 0 else 0` | 是否有泳池 | 奢侈品特征 |
| **HasFireplace** | `1 if Fireplaces > 0 else 0` | 是否有壁炉 | 舒适性特征 |
| **QualityScore** | `OverallQual * OverallCond` | 质量-条件综合评分 | 交互特征 |
| **LivingAreaPerRoom** | `GrLivArea / TotRmsAbvGrd` | 平均房间面积 | 房间大小指标 |

### 6.4 类别型特征编码策略

| 编码方式 | 适用特征 | 具体方法 |
|----------|----------|----------|
| **One-Hot Encoding** | MSSubClass, Neighborhood, MSZoning | 无序类别，类别数适中 |
| **Ordinal Encoding** | ExterQual, BsmtQual, KitchenQual, FireplaceQu, GarageQual | 质量等级（Ex>Gd>TA>Fa>Po） |
| **Target Encoding** | Neighborhood（25类） | 高基数类别，用目标均值编码 |
| **Binary Encoding** | HasAlley, HasFence, HasPool | 二值化高缺失率特征 |

### 6.5 针对RMSE优化的特殊建议

1. **对数变换目标变量**：由于RMSE对大误差惩罚重，使用`log(SalePrice)`可使误差在不同价格区间更均衡
   - 预测时：`pred = exp(model.predict(X))`
   - 这样实际优化的是百分比误差而非绝对误差

2. **分位数分析**：识别高价位房屋（>Q3+1.5IQR）的特征模式，确保模型对高端房的预测精度

3. **异常值处理**：LotArea等特征存在极端值，考虑：
   -  winsorization（缩尾处理）
   - 或删除明显异常的记录（如LotArea > 50,000）
