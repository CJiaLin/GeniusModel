# Model Selection Heuristics

ML 模型选择启发式规则与最佳实践技能包。

## 适用场景

- 模型训练阶段的算法选择
- 分类 / 回归 / 集成模型的选择与调优
- 超参数搜索策略

## 包含章节

| 章节 | 内容 |
|------|------|
| classification-models | 分类模型选择指南（逻辑回归、SVM、树模型、神经网络等） |
| regression-models | 回归模型选择指南（线性回归、正则化、树模型、KNN 等） |
| ensemble-methods | 集成学习方法（Bagging、Boosting、Stacking） |
| hyperparameter-tuning | 超参数调优策略（GridSearch、RandomSearch、Bayesian、早停等） |

## 使用原则

- 从简单模型开始，逐步增加复杂度
- 始终使用交叉验证评估模型性能
- 综合考虑精度、训练时间、可解释性
